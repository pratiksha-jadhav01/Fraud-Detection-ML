# Experimental Results

## Purpose
This directory stores the outputs generated by the financial fraud detection experiments.

## Models Evaluated
1. Logistic Regression
2. Decision Tree
3. Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- ROC-AUC

## Planned Output Files
- `metrics_summary.csv` — Model performance comparison.
- `confusion_matrices.png` — Visual comparison of model predictions.

## Note
The output files should be generated from the actual notebook results. No experimental results are fabricated in this documentation.
