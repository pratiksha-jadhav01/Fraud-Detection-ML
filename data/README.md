# Dataset Documentation

## Project
Machine Learning in Detecting Financial Fraud

## Dataset Description
The project uses a synthetic financial transaction dataset containing 1,000 records and 15 columns.

The target column is `FraudIndicator`:
- `0` — Legitimate transaction
- `1` — Fraudulent transaction

## Purpose
The dataset is used to explore transaction patterns, preprocess features, and train machine learning classification models.

## Data Processing
1. Load and inspect the dataset.
2. Check data types and missing values.
3. Prepare features and the target variable.
4. Split the data into training and testing sets.
5. Apply SMOTE only to the training data.

## Important Note
This is a synthetic educational dataset, not verified real-world financial data. The original dataset file should be added here if it is available and permitted to be shared.
