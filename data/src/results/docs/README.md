# Technical Documentation

## Project Title
Machine Learning in Detecting Financial Fraud

## Problem Statement
Financial fraud can cause financial losses. Machine learning classification models can help identify potentially suspicious transactions from transaction-related features.

## Objectives
- Prepare transaction data for machine learning.
- Address class imbalance using SMOTE.
- Train and compare three classification models.
- Evaluate model performance using appropriate metrics.
- Maintain version control and support reproducibility.

## Technology Stack
- Python
- Google Colab / Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Imbalanced-learn
- Git and GitHub

## Execution
1. Open the notebook in Google Colab.
2. Provide the required dataset.
3. Install the dependencies listed in `requirements.txt`.
4. Run the notebook cells in order.
5. Review the evaluation metrics and model comparisons.

## Limitations
The dataset is synthetic, so results may not generalize to real financial transactions. Further testing on verified real-world data is needed.
