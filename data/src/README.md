# Source Code Documentation

## Purpose
This directory is intended for reusable Python code for the financial fraud detection prototype.

## Planned Modules
- `preprocessing.py` — Data preparation and feature engineering.
- `model.py` — Training and prediction using classification models.
- `evaluation.py` — Calculation of performance metrics and confusion matrices.

## Models
- Logistic Regression
- Decision Tree
- Random Forest

## Current Implementation
The machine learning workflow is currently available in the Jupyter notebook at the repository root. Separate Python modules can be added when the code is organized into reusable components.
