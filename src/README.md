# Source Code Documentation

## Purpose
This directory is intended for reusable Python source code for the financial fraud detection prototype.

## Planned Modules
- `preprocessing.py` — Data preparation and feature engineering.
- `model.py` — Training classification models.
- `evaluation.py` — Calculating evaluation metrics and generating confusion matrices.

## Models
- Logistic Regression
- Decision Tree
- Random Forest

## Current Status
The existing implementation is available in the Experiment 6 Jupyter notebook. Separate Python modules will be added when the notebook code is organized into reusable components.
