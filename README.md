# Machine Learning in Detecting Financial Fraud

## Project Overview
This project develops a machine learning prototype to identify potentially fraudulent financial transactions using classification algorithms.

## Problem Statement
Financial fraud can cause significant financial losses. Machine learning can help identify suspicious transaction patterns and support faster fraud detection.

## Objectives
- Prepare and preprocess transaction data.
- Handle class imbalance using SMOTE.
- Train Logistic Regression, Decision Tree, and Random Forest models.
- Evaluate model performance using accuracy, precision, recall, F1-score, confusion matrices, and ROC-AUC.
- Compare the models and interpret their results.

## Technologies Used
- Python
- Google Colab / Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Imbalanced-learn (SMOTE)
- Git and GitHub

## Methodology
1. Load and inspect the dataset.
2. Perform data preprocessing and exploratory data analysis.
3. Prepare features and target labels.
4. Split the data into training and testing sets.
5. Apply SMOTE to the training data.
6. Train and evaluate the classification models.
7. Compare the results and interpret the findings.

## Dataset
The project uses a synthetic transaction dataset containing 1,000 records. It is designed for educational experimentation and does not represent verified real-world transaction records.

## Models
- Logistic Regression
- Decision Tree
- Random Forest

## Results
The models are evaluated and compared using classification metrics and confusion matrices. Refer to the notebook for the actual experimental results.

## Limitations
- The dataset is synthetic and may not represent real financial fraud patterns.
- Results may differ on real-world datasets.
- Further validation is needed before any real financial deployment.

## Future Scope

- Improve model evaluation and explainability.
