# Testing Documentation

## Purpose
This directory is intended for testing the financial fraud detection prototype.

## Planned Tests
1. Verify that the dataset loads correctly.
2. Check that the target column contains valid class labels.
3. Verify that preprocessing produces valid feature values.
4. Confirm that SMOTE is applied only to training data.
5. Check that trained models return valid predictions.
6. Verify that evaluation metrics can be calculated.

## Current Status
These tests are planned. Automated test scripts will be added when implemented.
